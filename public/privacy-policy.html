🔐 Privacy Policy – OPAS Labs

Effective Date: August 2, 2025

Jurisdiction: Kerala, India

Developer: Personal project by Telegram user @mohdrishad

1. Purpose

This Privacy Policy explains how OPAS Labs handles data when users interact with our phishing simulation tools and services.

2. Data Collection via Simulation Links

Data is only collected after the user clicks “I Understand & Proceed” on the security disclaimer page. Until then, no data is sent or stored.

The data collected may include:

  • Browser and operating system
  • Language and timezone
  • Device hardware: CPU, RAM, GPU
  • Screen resolution
  • Battery level and charging status
  • Network type, latency, and IP address
  • Approximate location and GPS (if permitted)

3. No Personal Data or Credentials Collected

  • No usernames, passwords, or credentials are requested or stored
  • No login forms or traps are used
  • No personal identifiers are recorded

4. Data Handling and Delivery

Data is forwarded directly and only to the Telegram account of the user who created the simulation link. This is done via a Telegram bot using the submitted chat ID.

OPAS Labs does not store any data on its servers, and even the developer cannot access it once sent.

5. Use of Third-Party Services

We use spoo.me as a URL shortening service to create 24-hour temporary links.

We use the Telegram Bot API to deliver simulation results to the link creator's Telegram account.

For IP geolocation and network details, we also use a third-party IP information provider. Their privacy policies apply independently.

6. Data Retention

We do not store data. No logs, databases, or backups are kept. Once the data is forwarded, it is no longer available to OPAS Labs.

7. Data Deletion

Because no data is retained, we cannot fulfill deletion requests. There is nothing to delete.

8. Link Expiry

All simulation links expire automatically after 24 hours. They cannot be manually deleted or extended.

9. User Responsibility

Users must not share simulation links without informing others that the links are part of a phishing test. Anyone misusing or modifying this project for harmful purposes is solely responsible for their actions.
