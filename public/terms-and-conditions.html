1. Overview

OPAS Labs is a personal, unlicensed cybersecurity simulation tool created for ethical testing and educational purposes. It simulates phishing pages to help users learn how phishing works, assess browser/device exposure, and train in cybersecurity awareness.

2. Age Restriction

This service is strictly for users 18 years or older. If you are under 18, do not access or use the tool.

3. Disclaimer Page & User Consent

Every link generated includes a mandatory warning screen:

⚠️ SECURITY WARNING
This is a simulated phishing link for educational purposes.
This link was created for cybersecurity training and self-testing.
If you did not request this link or arrived here unintentionally, please exit immediately.
No real malware or data theft will occur.

[Exit Immediately] [I Understand & Proceed]

Data is only collected after the user clicks "I Understand & Proceed." A loader is shown at that point — collection and transmission occur only then.

4. What Data Is Collected

After consent, the following non-personal, device-specific info is collected:

  • Browser and platform (e.g., Chrome, Linux)
  • Screen size, color depth, language, timezone
  • Hardware specs: CPU cores, RAM, GPU
  • Battery level and charging status
  • Network type, speed, latency, data saver status
  • IP address, city, region, country (IP-based)
  • GPS coordinates (if the browser allows)

No fake login inputs or personal credentials are collected.

5. Data Handling & Privacy

  • No data is stored on any server or backend.
  • No logs, no analytics, no saved IPs or messages.
  • Even the developer cannot access any data.
  • Collected data is sent only to the person who created the link, using the Telegram Chat ID they provided.

This tool uses a third-party IP lookup service (e.g., ipinfo.io) to fetch public IP data and region information. OPAS Labs does not control or store data from this service.
